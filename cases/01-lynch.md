# 린치 케이스 — 확정판

> **적용 대상**: 흑자 · 재무제표 3년 이상 · 경기순환주 아님 · 사업 단순
> **적용 제외**: 적자 성장주 → 베일리 기포드 케이스 / 경기순환주 → 별도 / 신규상장 → 판정 보류
>
> 이 문서는 확정본이다. 다음 케이스(BG)를 만드는 동안 건드리지 않는다.

---

## 산출물

```
① 등급   A / B / C / D / X
② 총평   등급 근거 + 등급을 바꿀 단일 사건
③ 추적   1~3개 (항목 / 확인처 / 승격조건 / 강등조건)
```

가격은 내지 않는다. 등급 A·B면 타점은 본인이 판단.

## STEP 3 — 분류별 검증

### 고성장주
1. 성장을 만드는 제품이 매출의 몇 %인가
2. 성장률이 유지되나
3. 확장 여지가 남았나
4. 확장이 복제되나
5. **PEG < 1 인가** ★아래 계산법 준수
6. 기관 보유·애널 커버가 낮은가
7. **킬**: 확장 둔화 / PEG 2 초과 / 성장률 꺾임

### 대형우량주
1. PER이 자기 역사 밴드 어디인가
2. 신사업이 본업을 갉아먹지 않나
3. **킬**: PER 역사 밴드 상단

### 자산주
1. 숨은 자산이 정확히 무엇인가
2. 장부가 vs 실제 가치
3. 현실화 경로와 시점이 있나
4. **킬**: 경영진이 팔 의지 없음

## ★ 개정 1 — PEG 계산법 (기저효과 보정)

```
PEG = Forward PER ÷ 【3년 EPS CAGR】
```

**단년 EPS 성장률 사용 금지.** 전년이 비정상적으로 낮거나 높으면 판정이 뒤집힌다.

**실측 사례**

| 종목 | 단년 성장 | 3Y CAGR | PEG(단년) | PEG(3Y) | 결과 |
|---|---|---|---|---|---|
| FORM | +135.4% | **2.0%** | 0.25 | **16.53** | 통과→**킬** |
| ORCL | +5.5% | 23.8% | 3.40 | **0.79** | 킬→**통과** |
| PWR | +55.6% | 27.0% | 0.65 | **1.33** | 통과→경계 |
| 고영 | +2.5% | **71.2%** | 12.09 | **0.42** | 킬→**통과** |
| 비에이치아이 | +8.1% | 83.8% | 3.48 | **0.34** | 킬→통과 |

FORM은 EPS가 4년간 0.65→0.69로 제자리인데 컨센만 +135%였다.
ORCL은 단년 둔화가 일시적이었다.

**보조 검사**: 컨센 EPS 성장률이 3년 CAGR의 3배를 초과하면 컨센 과대 의심.

**기준연도 통일**: PER은 전 종목 **당해연도(FY2026F) EPS** 기준으로 계산한다.
종목마다 27F·28F를 섞어 쓰면 비교가 무의미해진다.

**★R4**: 개정 후에는 **해당 케이스 전 종목을 다시 돌린다.**
미국에만 적용하고 한국을 빼먹어 고영을 잘못 X 처리했다.

## ★ 개정 2 — 연결/별도 구분

**반드시 연결 기준을 쓴다.**

DART 반기보고서 구조:
- `2. 연결재무제표` → **이걸 읽는다**
- `4. 재무제표` → 별도. 해외 자회사 제외됨

**실측 사례 (비나텍)**

| | 별도 | 연결 |
|---|---|---|
| GM | 13.4%→29.0% (개선) | 27.3%→**22.5%** (악화) |
| 영업이익 | -41억→**+72억** | -15억→**-10억** |
| 판정 | A | **X** |

해외 생산거점이 있는 기업에서 정반대 결론이 나온다.
미국 종목(SEC XBRL)은 연결이 기본이라 해당 없음.

---

## STEP 4 — 공통 킬

1. **재고·매출채권이 매출보다 +10%p 이상 빠르게 증가**
2. 부채 구조 감당 불가 (부채비율 200% 초과)
3. 순이익 ≫ 영업현금흐름 (발생액 크게 +)
4. 스토리를 2분 안에 설명 못함

---

## STEP 5 — 보조 검사

**A. 데이터 신선도** — 가격 두 소스 대조 (5일/5% 이상 차이 시 시계열)
**B. 섹터 알파** — 피어 4개+ 3M·12M 대비. 종목/업종 분리
**C. 손절폭 vs 변동성** — 무효화선 거리 < 일간변동성 ×2 → 경고
