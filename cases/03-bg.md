# 적자 성장주 케이스

> **적용 대상**: 최근 연간 영업적자 · 매출 존재 · 상장 3년 이상
> **적용 제외**: 흑자 → 린치 / 원자재·경기순환이 손익 지배 → 사이클 케이스로 이관
>
> 이 문서는 동결본이다. 개정하려면 관찰 기록에 같은 문제가 2회 이상 쌓여야 한다. (R2·R3)

---

## 구조 — 킬 2개, 정량축 3개, 내러티브 3문항

적자 성장주가 죽는 길은 두 개뿐이다.
**적자가 낫기 전에 돈이 마르거나, 적자가 구조라서 애초에 낫지 않거나.**
킬은 그 두 개에만 둔다. 나머지는 등급의 재료다.

```
킬      ① 생존(런웨이)   ② 단위경제(매출총이익)
정량축  ③ 주당 GP 성장   ④ 증분마진   ⑤ G-Score(파이프라인)
내러티브 ⑥ 경쟁우위 · 상승 경로 · 왜 시장이 모르나
```

---

## 킬 ① 생존 — 런웨이

> **런웨이 = 유동성 ÷ 분기 순소진 < 4분기 → X**

- **유동성** = 현금및현금성자산 + 단기금융상품
- **분기 순소진** = |영업활동현금흐름 − 유형자산 취득| ÷ 분기수
  - 캐펙스를 포함한다. 에버그린솔라를 죽인 것이 성장 캐펙스였다
  - 최근 반기 환산과 최근 4분기 환산 중 **짧은 쪽**
- **2회 연속 규칙**: 2분기 연속 위반 시 발동, 2분기 연속 충족 시 해제

### 캘리브레이션 (n=11, 파산 5 / 생존 6)

| 컷 | 파산 미포착 | 생존 오살 |
|---|---|---|
| 3분기 | **2건** (Lordstown 3.3, Proterra 3.4) | 0건 |
| 3.5분기 | 0건 | 0건 |
| **4분기** | **0건** | **1건 (Enphase 3.6)** |
| 6분기 | 0건 | 1건 (Enphase) |
| 8분기 | 0건 | 2건 (+ChargePoint 7.3) |

파산 표본: Fisker 1.6 · Lordstown 3.3 · Canoo 0.2 · Proterra 3.4 · WeWork 1.1
생존 표본: Enphase 3.6 · ChargePoint 7.3 · VirginGalactic 9.4 · PlugPower 33.1 · PLTR·TSLA 소진없음

3.5분기가 완벽 분리하지만 **Enphase 3.6과 Proterra 3.4 사이에 맞춘 값이라 과적합이다.**
4분기를 쓴다. Enphase 1건을 놓치는 대신 표본 하나에 기대지 않는다.

> **폐기 이력**: 최초에 6분기로 정했으나 근거가 없었다.
> 실측 결과 6분기는 4분기 대비 파산 포착이 늘지 않고 생존 오살만 같다. 이점이 없다.

## 킬 ② 단위경제 — 매출총이익

> **매출총이익 ≤ 0, 또는 매출 0 → X**

팔수록 손해면 규모가 커질수록 적자가 커진다. 성장이 문제를 푸는 게 아니라 키운다.

### 캘리브레이션 (같은 표본)

| | 결과 |
|---|---|
| 파산 포착 | **3건** — Fisker −104.8%, Canoo −167.9%, Proterra −7.8% |
| 파산 미포착 | Lordstown(매출 0 → 매출 조항이 포착), WeWork(GP 미공시) |
| 생존 오살 | **0건** |

정밀도가 완벽하다. 생존 6종목 중 매출총이익이 음수인 곳은 없었다.

**킬 ①·② 합산: 파산 5/5 포착, 생존 오살 1건(Enphase).**

## 정량축 ③ 주당 매출총이익 성장

> **주당 GP 성장 = (GP₁/주식수₁) ÷ (GP₀/주식수₀) − 1**

- **희석이 지표 안에 들어 있다.** 증자를 해도 주당 GP가 늘면 주주 몫이 는 것.
  따라서 희석에 대한 별도 킬·감점은 두지 않는다
- **기저 미형성**: 전년 GP ≤ 0 이거나 전년 GM < 5%면 성장률을 산출하지 않고
  "기저 미형성"으로 표기, 등급 상한 B
- 잠정 구간(표본 9개 기준, 개정 대상): **상 ≥ 30% / 중 10~30% / 하 < 10%**

## 정량축 ④ 증분마진 (킬에서 강등)

> **증분마진 = Δ영업이익 ÷ Δ매출**

성장이 적자를 줄이고 있는지 본다. **킬이 아니라 등급 재료다.**

### 왜 킬에서 내렸나 (n=11 실측)

| | 결과 |
|---|---|
| 파산 미포착 | **2건** — WeWork +312%, Canoo +26,973%(기저효과) |
| 생존 오살 | **4건** — ChargePoint −153%, Enphase·PlugPower·VirginGalactic(매출 감소 자동컷) |

**Enphase는 매출이 감소한 해에 자동컷을 맞았고, 그 뒤 급등했다.**
파산 2건을 통과시키고 생존 4건을 죽인다. 킬로 쓸 판별력이 없다.

> **폐기 이력**: 최초에 "증분마진 ≤ 0 → X"로 두고 ONDS·ASPI·LPTH를 X로 보냈다.
> 근거 없는 컷이었고, 실측 결과 오작동이 확인됐다. 등급축으로 내린다.

## 정량축 ⑤ Mohanram G-Score

피오트로스키의 성장주 대응물. 산업 중앙값 대비 8신호 — R&D·캐펙스 지출을 감점이 아니라 가점 처리한다.
**피어 중앙값이 필요하므로 세션에서 손으로 계산하지 않는다.** 발굴 파이프라인의 스크리닝 단계 몫.
산출되면 총평에 병기하고, 없으면 생략한다.

## 내러티브 ⑥ — 세 문항만 (BG 10문항 중 3·9·10)

숫자로 잴 수 없는 것만 남긴다.

| # | 질문 | 못 하면 |
|---|---|---|
| N1 | 경쟁우위가 무엇인가 | 성장해도 남이 가져간다 |
| N2 | 어떻게 하면 크게 오르나. 배수와 경로를 함께 답한다 | 상방을 설명 못하면 보유 기간을 정할 수 없다 |
| N3 | 왜 시장은 이걸 모르나 | 이미 반영된 가격이다 |

## 보조 검사 (전 케이스 공통)

A 데이터 신선도 · B 섹터 알파 · C 손절폭 vs 변동성 · D 연결 기준 강제 · F DART 추출 3원칙 · G 검산 게이트
**E(PEG)는 적용하지 않는다** — 적자 기업엔 정의되지 않는다.

## 등급

| 등급 | 조건 |
|---|---|
| **A** | 킬 통과 + ③ 상(≥30%) + ④ 플러스 + N1·N2·N3 전부 답 |
| **B** | 킬 통과 + ③ 상인데 ④ 마이너스이거나 N 하나 미흡, 또는 기저 미형성 |
| **C** | 킬 통과 + ③ 하, 또는 N 두 개 미흡 |
| **D** | 스토리를 2분 안에 설명 못함 |
| **X** | 킬 ①·② 중 하나 발동, 또는 대상 판별 탈락 |

가격(진입가·손절가·목표가)은 내지 않는다.
