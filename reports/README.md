# 원페이지 리포트

종목별 사업 현황 요약. **케이스 판정과는 별개 문서다.**

| | 원페이지 리포트 | 케이스 판정 |
|---|---|---|
| 목적 | 이 회사가 뭘 하는가 | 사야 하는가 |
| 근거 | 웹 검색 + 공시 | 케이스 로직 |
| 산출 | 사업·실적·이슈 요약 | 등급 + 추적항목 |
| 위치 | `reports/` | `data/watchlist.json` |

## 작성 절차

**1단계 — 정보 수집**
네 방향으로 나눠 검색한다.
- 사업 개요와 매출 구성
- 최근 분기 실적 (매출·영업이익)
- 최근 이슈 (신사업·규제·경쟁·수주)
- 증권사 목표주가·투자의견

부족하거나 상충하면 추가 검색으로 보완.

**2단계 — 선별**
신뢰도와 관련성 기준으로 추린다. 출처를 인용으로 표시해 어느 정보가 어디서 나왔는지 남긴다. 중복·구식 정보는 제외.

**3단계 — 압축**

| 섹션 | 내용 |
|---|---|
| 헤더 | 종목명·현재가·시총·날짜 |
| 사업 개요 | 주요 부문과 매출 구성 (2~3줄) |
| 최근 실적 | 분기 매출·영업이익, YoY/QoQ |
| 수주 | 신규수주·잔고 (해당 시) |
| 현재 이슈 | 신사업·수주·규제·경쟁 |
| 시장 평가 | 목표주가·투자의견 + 반론 |
| 핵심 지표 | PER·시총·EPS 요약표 |
| 정리 | 3~4줄. 무엇이 진짜고 무엇이 부담인가 |

## 원칙

- **한 장.** 스크롤 두 번 안에 끝난다
- **숫자는 출처와 함께.** 인용 없는 수치는 쓰지 않는다
- **시장 평가에는 반론도 넣는다.** 목표주가만 나열하지 않는다
- **정리에서 가격과 실적을 분리한다.** 좋은 회사와 좋은 주식은 다르다
- 판정하지 않는다. 등급은 케이스 로직의 몫
